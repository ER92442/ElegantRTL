# ElegantRTL - Shopify Theme

A production-ready, minimalist classic-modern Shopify theme with full RTL (Right-to-Left) support.

## Features

- **Full RTL Support**: Complete RTL implementation for Hebrew, Arabic, and other RTL languages
- **Minimalist Design**: Clean lines, ample white space, neutral palette with deep blue accents
- **Elegant Animations**: Smooth hover transitions, fade-ins, and keyframe animations
- **Responsive Design**: Mobile-first approach with proper breakpoints
- **Modern Typography**: Sans-serif fonts with clean, readable styling
- **Performance Optimized**: Fast loading with lazy loading and efficient CSS

## Theme Structure

```
ElegantRTL/
├── assets/          # CSS, JavaScript, and image assets
├── config/          # Theme settings
├── layout/          # Theme layout files
├── locales/         # Translation files (en, he)
├── sections/        # Reusable sections
├── snippets/        # Reusable code snippets
└── templates/       # Page templates
```

## RTL Implementation

The theme automatically detects RTL languages (Hebrew, Arabic) and:
- Sets `dir="rtl"` on the HTML element
- Loads RTL-specific CSS
- Reverses navigation menus, sliders, and grids
- Flips icons and arrows
- Uses logical CSS properties for proper alignment

## Installation

1. Upload the theme to your Shopify store
2. Customize colors, fonts, and settings in the theme editor
3. Configure sections for your homepage and other pages

## Customization

All theme settings can be customized through the Shopify theme editor:
- Colors and typography
- Layout and spacing
- Button and card styles
- Product card appearance
